Category Two: Algorithms and Data Structures

First Expired, First Out (FEFO) Inventory Allocation

For the Algorithms and Data Structures enhancement, I improved the inventory management process within the Orelia Clinic Management Software by implementing a First Expired, First Out (FEFO) allocation algorithm. The enhancement automatically prioritizes eligible medication inventory based on expiration date, helping ensure that inventory expiring soonest is used before newer inventory.

The algorithm retrieves eligible, non-expired inventory lots in expiration-date order and performs a linear traversal to determine how the required medication quantity should be allocated. When a single lot cannot satisfy the requested amount, the algorithm continues across multiple lots until the required quantity has been fulfilled. A new relational allocation structure also preserves the exact inventory lots and quantities associated with each injection.

Enhancement Highlights

  • Implemented FEFO inventory allocation based on medication expiration dates
  • Added expiration-date tracking to inventory records
  • Added linear traversal of ordered inventory lots to fulfill medication requirements
  • Supports allocation across multiple inventory lots
  • Records exact lot-by-lot inventory usage for each injection
  • Added transactional inventory deductions and restoration
  • Updated injection creation, modification, and deletion to support FEFO allocations
  • Preserved backward compatibility with injection records created before the enhancement
  • Added insufficient-inventory handling with 409 Conflict responses
  • Prevents partial inventory deductions when an allocation cannot be fulfilled
  • Improved data integrity and traceability through a one-to-many injection-to-allocation relationship

This enhancement demonstrates the use of algorithmic principles to solve a practical inventory-management problem while improving the reliability, traceability, and scalability of the original application.
